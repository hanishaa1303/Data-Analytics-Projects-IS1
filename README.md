Data Analyst Internship, where I worked on real-world datasets

 Projects Overview

 Project 1:Customer Churn Prediction  
Objective:
Predict which customers are likely to stop using a service 
To perform:
1.Use datasets like telecom, banking, or SaaS platforms.

2.Perform exploratory data analysis (EDA) to find churn patterns.

3.Use classification models (Logistic Regression, Random Forest, XGBoost).

4.Evaluate with accuracy, recall, and ROC-AUC.


Project 2: 3. Real-Time Sentiment Analysis on Twitter Data
